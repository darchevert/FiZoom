# FiZoom 🃏

Adaptation mobile (Android/iOS) du jeu à boire de cartes classiques **FiZoom**.

Règle originale : les joueurs piochent chacun leur tour une carte du jeu au centre de la table. Chaque carte/valeur déclenche un gage (ex : 2 = bois 2 gorgées, Dame = Fi-Zoom — cul sec et rejoue).

## Statut

Phase de cadrage — voir le rapport de faisabilité (lien à ajouter par l'équipe projet) pour :
